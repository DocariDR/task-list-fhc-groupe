Exercice pratique réalisé dans le cadre de ma formation en développement web chez **FHC Groupe Sarl**, à la suite du cours d'initialisation au JavaScript. L'objectif : construire une petite application de liste de tâches en JavaScript vanilla, sans framework.

## 🔗 Démo

[Cliquer sur moi](https://docaridr.github.io/task-list-fhc-groupe/)

## Fonctionnalités

- Ajout d'une tâche via un formulaire
- Suppression d'une tâche avec animation (apparition/disparition)
- Validation du champ (refus des entrées vides)
- Refus des doublons (une même tâche ne peut pas être ajoutée deux fois)
- Délégation d'événements pour gérer les tâches créées dynamiquement

## Stack technique

- HTML5
- CSS3 (animations via `@keyframes`)
- JavaScript (vanilla, DOM, délégation d'événements)
- [Material Symbols](https://fonts.google.com/icons) pour l'icône de suppression

## Structure du projet

```
task-list-fhc-groupe/

```

## Pistes d'amélioration

- Persistance des tâches via `localStorage`
- Modification d'une tâche existante (édition inline)
- Marquer une tâche comme terminée (checkbox / barré)
